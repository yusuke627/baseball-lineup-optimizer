# 検証結果

`backend/tests/` の各テストの実行結果に基づく。実行コマンド: `pytest -v`（`backend/`ディレクトリで実行）。

## 1. 確率の整合性チェック

`test_transition_probabilities.py`: 任意の打者イベント確率について、24個の全ての `(走者状況, アウト数)` 状態からの遷移確率の合計が1.0（誤差1e-9以内）になることを確認。→ **PASS**

## 2. 単調性チェック

`test_monotonicity.py`: 以下をいずれも確認。

- 本塁打確率を+5pt・アウト確率を-5pt すると、1試合の期待得点が増加する → **PASS**
- 四球確率を+5pt・アウト確率を-5pt すると、1試合の期待得点が増加する → **PASS**
- 三振確率を+5pt・単打確率を-5pt すると、1試合の期待得点が減少する → **PASS**

## 3. 案A（マルコフ連鎖）と案B（モンテカルロ）の突き合わせ

`test_ab_convergence.py`: 同一の打者イベント確率(9人分同一の"平均的な打者"を想定)を用い、

- 案A（マルコフ連鎖、厳密計算）: **4.0607 点/試合**
- 案B（モンテカルロ、3万試行、seed=42）: 平均 **4.0428 点/試合**

相対誤差は約0.4%であり、許容基準（3%以内）を満たすことを確認。→ **PASS**

（参考：モンテカルロは1試行あたりの得点分散が大きく、標準偏差は約2.9点/試合であった。試行回数をさらに増やせば誤差はより収束すると考えられる。）

## 4. 既知の実測値とのベンチマーク

`test_benchmarks.py`: 概算のMLB平均的な打者9人（打率.245前後、出塁率.330前後を想定した確率分布）を並べた場合の1試合期待得点が、近年のMLB平均的な得点レンジ（3.5〜5.5点/試合）に収まることを確認。

- 算出値: **4.0607 点/試合**（143試合換算: 約580.7点）

実際の得点は相手投手の力量・パークファクター等モデル外要因の影響も受けるため、このベンチマークは「モデルが常識的に妥当な範囲の値を出しているか」の粗い確認として位置づける。

## 5. 先行研究・公開値との照合（年代統一版）

### 5-1. 検証方法の訂正

当初の検証では、本モデルのテスト用打者確率（架空の近似値）と、複数の異なる年代（1963年、2008年、2012年、2010-2015年等）の得点期待値表を比較していた。これは「モデルが正しいかどうか」と「異なる年代・異なる打者を比較したことによるズレ」を切り分けられておらず、検証として不十分だった。そこで、**年代・出典を完全に統一した再検証**を行った。

### 5-2. 年代統一の方法

- **進塁確率**：Baseball Prospectus記事（2003年MLBデータ）の値を使用（既存のDEFAULT_ADVANCE_PROBSと同一）
- **比較対象のRE24表**：同じBaseball Prospectus記事に掲載されている2003年のRE24表そのものを使用（自前でRE24表を算出する必要はなかった）
- **打者成績**：2003年のMLB全30球団（AL・NL）のチーム打撃成績合計をBaseball-Referenceから取得し、リーグ平均のイベント確率を算出

これにより、進塁確率・打者成績・比較対象のRE24表のすべてが2003年という同一年代で統一された。

### 5-3. 結果

| | 平均絶対誤差(MAE) | バイアス（平均誤差） |
|---|---|---|
| 打球アウトでの進塁を考慮しない場合（現行の実装） | 0.1195点 | -0.1086点（系統的に過小評価） |
| 打球アウトでの三塁走者生還(0.651の確率)を追加した場合 | **0.0369点** | **+0.0088点** |

「打球アウトでの進塁を考慮していない」という既知の簡略化を1点補正するだけで、24状態全体の平均絶対誤差が約1/3に縮小し、系統的なバイアスもほぼ解消された。これは、モデルの根幹となる状態遷移・マルコフ連鎖の実装が正しく、観測されていたズレの大部分が意図的な簡略化に起因することの強い裏付けとなる。

### 5-4. 残った誤差についての考察

改良後も、満塁・1アウトの状態で+0.21点の過大評価が残った。この原因として、以下の仮説が有力だと考えられる（実装は変更せず、考察のみ記録する）。

**仮説：併殺確率が状況によらず一律（シーズン平均）になっているため**

本モデルの併殺(GIDP)確率は、そのシーズンの全打席数に対する併殺打の発生率をそのまま使っている。しかしこれは「併殺が起こりうる場面（一塁に走者がいる状況）」と「併殺が起こりえない場面（一塁に走者がいない状況）」を区別せずに平均した値であり、実際には併殺が起こりうる場面に限定した発生率はシーズン平均よりも大幅に高くなる。

満塁の状態はまさに「一塁に走者がいる＝併殺が起こりうる状況」だが、本モデルはここでも薄められたシーズン平均の確率しか併殺に割り当てず、残りの確率質量の大部分を通常のアウト（5-3節で導入した「打球アウトでの三塁走者生還(0.651)」の対象）に振り分けてしまう。この結果、本来は併殺として処理されるべき打席の一部が「三塁走者が生還するアウト」として扱われ、得点期待値を余分に押し上げていると考えられる。

この仮説は過大評価という観測結果の方向性とは整合するが、これだけで+0.21点のズレをすべて説明できるかは検証しておらず、満塁特有の守備側の戦術変化（本塁封殺を狙うか併殺を優先するかの判断等）など、他の未モデル化要因が残っている可能性もある。

なお、この仮説の対処法（状況別の併殺発生率を別途モデル化する等）は、進塁確率という文献に基づくパラメータの変更とは別の話であり、今回は考察にとどめ、`DEFAULT_ADVANCE_PROBS`等の既存パラメータの変更は行っていない。今後の拡張候補として検討する。

### 5-5. 本モデルは決定論的計算(案A)であることの確認

本検証はすべて案A（マルコフ連鎖による厳密計算）で行っており、乱数を使用していない。したがって「試行回数を増やせば真の値に収束する」という考え方はそもそも適用できない。観測されるズレは、モデルの前提（状況非依存の確率適用、一部プレーの未モデル化）に起因するものであり、統計的なブレではない。

### 5-6. 未実施の項目

Bukiet, Harold and Palacios (1997) や D'Esopo and Lefkowitz (1977) 等の先行研究に掲載されている具体的な打線・チーム単位の計算例との直接照合は、今回も実施していない。ただし、今回実施した「年代を統一した24状態RE表との比較」は、それよりも網羅的かつ定量的な検証であり、優先度としてはこちらを先に実施する価値があったと考えている。
